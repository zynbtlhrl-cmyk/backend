# منصة تعليمية - Backend API

## نبذة عن المشروع

هذا المشروع عبارة عن واجهة برمجية (API) تم تطويرها باستخدام Laravel لإدارة منصة تعليمية مرتبطة بتطبيق Flutter.

يتيح النظام للإدارة التحكم الكامل بالمحتوى التعليمي والمستخدمين من خلال لوحة تحكم خاصة بالإدمن.

---

## مميزات لوحة الإدارة (Admin)

### إدارة الأقسام

* إضافة قسم جديد.
* تعديل بيانات القسم.
* حذف القسم.
* عرض جميع الأقسام.

### إدارة الكورسات

* إضافة كورس جديد.
* تعديل بيانات الكورس.
* حذف الكورس.
* عرض جميع الكورسات.
* ربط الكورسات بالأقسام.

### إدارة الفيديوهات

* إضافة فيديو جديد.
* تعديل بيانات الفيديو.
* حذف الفيديو.
* عرض جميع الفيديوهات.
* ربط الفيديوهات بالكورسات.

### إدارة المستخدمين

* عرض جميع المستخدمين المسجلين.
* حذف المستخدمين.
* متابعة بيانات المستخدمين.

---

## مميزات المستخدم

يمكن للمستخدم من خلال تطبيق Flutter:

* إنشاء حساب جديد.
* تسجيل الدخول.
* استعراض الأقسام التعليمية.
* عرض الكورسات المتاحة.
* مشاهدة الفيديوهات التعليمية.
* إضافة الكورسات إلى المفضلة.
* إدارة الملف الشخصي.

---

## قاعدة البيانات

يتكون النظام من الجداول الرئيسية التالية:

* Users
* Categories
* Courses
* Videos
* Favorites

مع وجود علاقات بين الأقسام والكورسات والفيديوهات لتنظيم المحتوى التعليمي.

---

## الهدف من المشروع

يهدف المشروع إلى توفير منصة تعليمية متكاملة تسمح للإدارة بإدارة الأقسام والكورسات والفيديوهات والمستخدمين بسهولة، وتمكن المستخدمين من الوصول إلى المحتوى التعليمي عبر تطبيق Flutter بطريقة منظمة وسهلة الاستخدام.
